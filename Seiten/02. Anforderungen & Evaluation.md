## Evaluation der Systemanbindung

### FortiGate
Für die Einbindung einer FortiGate Firewall in die Monitoring-Plattform wurden verschiedene technische Anbindungsvarianten betrachtet. Im bestehenden Monitoring der Intecso AG werden die FortiGate Firewalls primär über ihre Erreichbarkeit überwacht. Für den MVP soll deshalb mindestens eine vergleichbare Verfügbarkeitsüberwachung umgesetzt werden. Eine detaillierte Erfassung interner Systemmetriken wie CPU-Auslastung, Arbeitsspeicher oder Interface-Durchsatz ist für diesen Anwendungsfall nicht erforderlich.

Für den MVP werden folgende Varianten betrachtet:

1. **SNMP über Prometheus SNMP Exporter**  
   Die FortiGate stellt System- und Netzwerkmetriken über SNMP bereit. Der Prometheus SNMP Exporter kann diese Informationen abfragen und für Prometheus verfügbar machen. FortiGate unterstützt SNMP-Abfragen sowie SNMP-Traps. Diese Variante ermöglicht ein detaillierteres Monitoring, benötigt jedoch zusätzliche Konfiguration auf der FortiGate und im SNMP Exporter.

2. **FortiOS REST API über einen Exporter**  
   FortiOS stellt eine REST API zur Verfügung, über welche unter anderem Systeminformationen und Statistiken abgefragt werden können. Für die Verwendung mit Prometheus wird eine zusätzliche Komponente benötigt, welche die API abfragt und die erhaltenen Informationen als Prometheus-Metriken bereitstellt. Zusätzlich müssen ein API-Administrator und ein entsprechender API-Token verwaltet werden.

3. **Erreichbarkeitsüberwachung über Prometheus Blackbox Exporter**  
   Der Prometheus Blackbox Exporter ermöglicht die Überwachung einer FortiGate mittels ICMP. Damit kann die Firewall regelmässig per Ping auf ihre Erreichbarkeit geprüft und das Ergebnis als Prometheus-Metrik erfasst werden. Dies entspricht grundsätzlich dem heute eingesetzten Ansatz zur Verfügbarkeitsüberwachung.

   Diese Variante setzt jedoch voraus, dass die zu überwachende FortiGate vom Standort der Monitoring-Plattform aus per ICMP erreichbar ist. Dies ist nicht bei allen durch die Intecso AG betreuten FortiGate Firewalls gegeben, da nicht jedes Gerät über eine direkt erreichbare öffentliche IP-Adresse verfügt.

   Die betreuten FortiGate Firewalls sind zusätzlich in FortiGate Cloud registriert und können darüber zentral verwaltet werden. FortiGate Cloud bietet Remote-Management sowie eine Cloud REST API. Diese Möglichkeit wird deshalb als potenzielle Alternative für Systeme berücksichtigt, die von der Monitoring-Plattform nicht direkt erreichbar sind.

Da für den vorgesehenen Anwendungsfall primär die Erreichbarkeit der FortiGate relevant ist, werden die Varianten insbesondere hinsichtlich Implementierungsaufwand, Sicherheitsaspekten, benötigten Berechtigungen, Integration in Prometheus sowie der Nähe zum bestehenden Monitoring bewertet.

#### Bewertung der Varianten

Da die FortiGate Firewalls im bestehenden Monitoring der Intecso AG primär über ihre Erreichbarkeit überwacht werden, wird für den MVP keine detaillierte Erfassung interner Firewall-Metriken vorausgesetzt. Die Bewertung orientiert sich deshalb insbesondere an der Praxistauglichkeit, dem Implementierungsaufwand und der Vergleichbarkeit mit dem heutigen Monitoring.

| Kriterium | SNMP Exporter | REST API / FortiGate Exporter | Blackbox Exporter (ICMP) |
|---|---:|---:|---:|
| Erreichbarkeitsüberwachung | 5 | 5 | 5 |
| Implementierungsaufwand | 3 | 2 | 5 |
| Zusätzliche FortiGate-Konfiguration | 3 | 2 | 5 |
| Zugangsdaten / Secrets notwendig | 3 | 2 | 5 |
| Integration in Prometheus | 4 | 4 | 5 |
| Nähe zum bestehenden Monitoring | 2 | 2 | 5 |
| Eignung für den MVP | 3 | 3 | 5 |

Für den MVP wird deshalb der **Prometheus Blackbox Exporter mit ICMP** bevorzugt.

Der Blackbox Exporter prüft die FortiGate mittels ICMP auf Erreichbarkeit und stellt das Ergebnis als Prometheus-Metrik zur Verfügung. Damit kann der Zustand zentral über Prometheus erfasst, in Grafana visualisiert und später über Alertmanager alarmiert werden.

SNMP und die FortiOS REST API ermöglichen zwar ein detaillierteres Monitoring, würden für die Anforderungen des MVP jedoch zusätzliche Konfiguration, Berechtigungen und teilweise die Verwaltung von Zugangsdaten erfordern. Da diese zusätzlichen Metriken für den vorgesehenen FortiGate-Anwendungsfall aktuell keinen notwendigen Mehrwert darstellen, werden diese Varianten für den MVP nicht weiterverfolgt.

**Quellen:**
>- Prometheus: [Blackbox Exporter](https://github.com/prometheus/blackbox_exporter) – unterstützt unter anderem ICMP-Probes zur Überwachung der Erreichbarkeit von Endpunkten.
>- Prometheus Community: [FortiGate Exporter](https://github.com/prometheus-community/fortigate_exporter) – alternative API-basierte Variante für detailliertere FortiGate

#### Empfehlung für den MVP [FortiGate]
Für den MVP wird die **Erreichbarkeitsüberwachung mittels ICMP über den Prometheus Blackbox Exporter** gewählt. Dieser Ansatz entspricht dem heutigen Monitoring und ermöglicht eine einfache Integration in Prometheus. Der Blackbox Exporter unterstützt ICMP nativ.

Da nicht alle betreuten FortiGate Firewalls direkt per ICMP erreichbar sind, wird **FortiGate Cloud** als mögliche spätere Erweiterung berücksichtigt. Die vorhandene REST API könnte zukünftig zur Überwachung nicht direkt erreichbarer Geräte verwendet werden, ist jedoch nicht Bestandteil des MVP.
